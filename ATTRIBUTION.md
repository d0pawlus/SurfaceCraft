# Attribution

Every non-code file in this repository has a row here (checked by `cargo xtask assets`).

Policy:
- No asset, text, icon, layout or data file from QuickSurface (KVS Ltd) or Geomagic Design X
  (Hexagon) is ever added, not even sample scans. Their sample scans may be used only locally
  through `SURFACECRAFT_LOCAL_CORPUS`, by tests that are off by default; nothing derived from
  them (results, screenshots) is committed.
- Test meshes in the repository are synthetic (generated by `surfacecraft_geom::synth`) or come
  from openly licensed sources listed below with their licence. Openly licensed scans that are
  too large to commit are downloaded by a script ("External test models").
- Fonts are egui's bundled defaults (see THIRD-PARTY-LICENSES.txt).

## External test models (not in the repository)

Four scans used as the open test corpus. They are too large to commit (105 to 190 MB each), so
`xtask/fetch-artec-corpus.sh <dir>` downloads them from the publisher, pinned by version and
SHA-256, and the tests read them through `SURFACECRAFT_ARTEC_CORPUS` (off by default). The script
saves the licence text of each archive beside the model. The models are used unmodified; SurfaceCraft
is not connected with, sponsored or endorsed by Artec Group.

| Model | Author | Source | Licence |
|---|---|---|---|
| Car rim (`car-rim.stl`) | Artec Group inc. (www.artec3d.com) | https://www.artec3d.com/3d-models/car-rim | CC BY 3.0 Unported per the licence file in the archive (the page states CC BY 4.0) |
| Four-cylinder engine (`four-cylinder-engine.ply`) | Artec Group inc. (www.artec3d.com) | https://www.artec3d.com/3d-models/four-cylinder-engine | as above |
| Industrial part (`industrial-part.obj`) | Artec Group inc. (www.artec3d.com) | https://www.artec3d.com/3d-models/industrial-part | as above |
| Water pump (`water-pump.ply`) | Artec Group inc. (www.artec3d.com) | https://www.artec3d.com/3d-models/water-pump | as above |

Anything derived from these models that is committed or published (a crop, a decimated copy, a
screenshot) carries the same credit and says that it was modified.

## Algorithm references (no source copied)

Methods implemented from publications; no code of the reference implementations is used.

| Code | Reference | Notes |
|---|---|---|

| crates/geom/src/handles/ | Guskov, Wood, "Topological Noise Removal", Graphics Interface 2001 (small handles are found as neighbourhoods of the surface that are not disks, cut out and the holes filled) | Written from the paper; no code was read or used. Detection by geodesic balls around seeds a quarter of a ball apart and the Euler characteristic of each connected part of a ball (instead of the paper's growing wavefront), the checks on the fill (share of the fill and of what was cut out farther than the tolerance, pinched vertices, a piece cut loose) and the multi-scale passes are our own. |
| crates/fit/src/mls.rs | moving least squares projection (Levin 1998; Alexa et al. 2003) | Gaussian-weighted local quadric. |
| crates/align/src/pair/ | Rusu, Blodow, Beetz, "Fast Point Feature Histograms (FPFH) for 3D registration", ICRA 2009 (descriptors); Fischler, Bolles, "Random Sample Consensus", CACM 1981 (RANSAC over descriptor matches); Besl, McKay 1992 and Chen, Medioni 1991 (ICP, already in `icp.rs`) | Written from the papers; no code of PCL, Open3D, Super4PCS or Go-ICP (GPL) was read or used. | crates/align/src/global/ | Lu, Milios, "Globally consistent range scan alignment for environment mapping", Autonomous Robots 1997 (network of pairwise poses solved together); Pulli, "Multiview registration for large data sets", 3DIM 1999 (virtual correspondences from the pair poses, relaxation of all views at once); Grisetti, Kuemmerle, Stachniss, Burgard, "A tutorial on graph-based SLAM", 2010 (Gauss-Newton with damping on a pose graph, one node held fixed); Fischler, Bolles 1981 (consensus over random spanning trees to find pair poses that are wrong) | Written from the papers; no code of g2o (LGPL), Open3D, PCL, Ceres or any other implementation was read or used. The cost on virtual point pairs, the Huber weight per edge, the consensus search over seeded random spanning trees and the cycle-wise loop-closure figures are our own. |
| crates/fit/src/param.rs | Floater, "Mean value coordinates", Computer Aided Geometric Design 20(1), 2003 (mean-value weights of the interior system); Liu, Zhang, Xu, Gotsman, Gortler, "A Local/Global Approach to Mesh Parameterization", SGP 2008 (as-rigid-as-possible relaxation); Saad, *Iterative Methods for Sparse Linear Systems* (conjugate gradients, BiCGSTAB) | Written from the papers; no code of a mesh-processing library (libigl, CGAL and the like) was read or used. | crates/kernel/src/vpatch.rs, crates/kernel/src/vpatch/ | Welch, Witkin, "Variational surface modeling", SIGGRAPH 1992, and Celniker, Gossard, "Deformable curve and surface finite-elements for free-form shape design", SIGGRAPH 1991 (thin-plate energy, linear position, tangent and curvature conditions); Piegl, Tiller, *The NURBS Book* (basis function derivatives, via solidcore); Golub, Van Loan, *Matrix Computations* (null-space method, QR and SVD of the constraint rows) | Written from the books and papers; no code of a CAD or surface-fitting library was read or used.
