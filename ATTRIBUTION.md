# Attribution

Every non-code file in this repository has a row here (checked by `cargo xtask assets`).

Policy:
- No asset, text, icon, layout or data file from QuickSurface (KVS Ltd) or Geomagic Design X
  (Hexagon) is ever added, not even sample scans. Their sample scans may be used only locally
  through `SURFACECRAFT_LOCAL_CORPUS`, by tests that are off by default; nothing derived from
  them (results, screenshots) is committed.
- Test meshes in the repository are synthetic (generated by `surfacecraft_geom::synth`) or come
  from openly licensed sources listed below with their licence.
- Fonts are egui's bundled defaults (see THIRD-PARTY-LICENSES.txt).
