# M6 — Web (wasm) + MCP + asystent AI: plan

> Źródło: design doc §5, §7, §8 (M6), §11 (web warunkowy), spike §3.5. Gałąź `m6-web-mcp-ai`.

## Zakres
1. **MCP** (`crates/mcp`): własny JSON-RPC 2.0, jedna wiadomość na linię (bez `rmcp`), protokoły
   2025-06-18 / 2025-03-26 / 2024-11-05. **Każda komenda silnika jest narzędziem** (`mesh.import` → `mesh_import`,
   schemat wejścia i wyjścia z rejestru) + narzędzia ogólne: `list_commands`, `describe_command`, `execute`,
   `batch` (rollback przez undo), `undo`, `redo`, `inspect_design`, `screenshot`; zasoby `surfacecraft://design`,
   `surfacecraft://commands`. `surfacecraft-cli mcp` — tryb **bridged** do działającej aplikacji desktop (kanał
   sterowania na `127.0.0.1`, losowy port, token sesji, plik discovery w katalogu tymczasowym; żądania wykonywane na
   wątku UI między klatkami), bez aplikacji — sesja headless (pliki domyślnie wyłączone, `--allow-files`), zrzuty
   ekranu renderem offscreen.
2. **Web**: `surfacecraft-web` (eframe WebRunner, WebGPU/WebGL), menu „Web files”: import siatki/STEP z dysku
   przeglądarki (rfd async → te same komendy z `data` base64), pobieranie STL/STEP. `cargo xtask web` buduje bundle
   (`wasm-bindgen`) do `apps/surfacecraft-web/dist`. **Podzbiór (§11):** wszystkie komendy poza ścieżkami plików
   (`allow_files = false`), limit siatek 5 mln trójkątów (pamięć przeglądarki), bez kanału sterowania/MCP i bez zrzutów
   offscreen, asystent tylko z dostawcą wstrzykniętym przez hosta.
3. **Asystent AI** (`crates/ai`): tryby `align` i `workflow`, wejście = cel + PNG viewportu, pętla narzędzi
   niezależna od dostawcy (narzędzia = komendy ze schematami; tryb align ogranicza listę), wszystkie zmiany cofalne.
   Dostawcy: `ScriptedProvider` (testy) i `CommandProvider` (program z `SURFACECRAFT_AI_COMMAND`: żądanie JSON na
   stdin, odpowiedź JSON na stdout). **Wybór usługi LLM i klucza API należy do użytkownika** — nie jest wpisany w kod.
   GUI: panel Assistant; CLI: `surfacecraft-cli assist <align|workflow> <cel>`.

## Bramki (testy `gate_m6_*`)
- MCP obejmuje wszystkie komendy: `tools/list` zawiera każdą komendę rejestru; przepływ przez stdio (synth → segment
  → STEP) działa (`gate_m6_mcp_stdio_exposes_and_runs_every_command`); bridge do kanału sterowania.
- Web: `cargo xtask wasm` (CI) + podzbiór bez plików (`gate_m6_web_subset_runs_without_files`); bundle uruchomiony
  w przeglądarce (komenda z palety tworzy siatkę widoczną w viewporcie — sprawdzone ręcznie, zrzut w STATUS).
- Asystent: tryb align wykonuje wywołania dostawcy jako komendy i cofa się undo (`gate_m6_assistant_align_mode`),
  panel GUI i `assist` w CLI z programem-dostawcą.
